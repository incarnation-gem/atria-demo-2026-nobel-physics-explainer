## 关键参数 / 决策（量化驱动）

- **SC03 橙光斑幅度受控**：初版 r340×α0.36 的呼吸/灭光逐帧变化把 motion_check 的 hold 打穿到 0f（灭光段 diff 1.518 ≥ HOLD_THR 1.5）。按「小面积动作 → 加大幅度而不是加元素」反过来收：r256×α0.28，灭光段 diff ≈0.7，hold 恢复 75f；frame_metrics 主角柔光反而从中位 808 升到 1129（hero box 更贴合）。
- **SC04 地球 scaleIn 修复**：初版只算了 `es` 没套到 EarthIcon 上，地球一闪即满尺寸，1359–1482 整段 123f 无变化（最长静止 4.1s）。套 `<g transform=translate scale translate>` 后最长静止降到 2.4s。
- **SC04 波纹改连续环形**（every 42→30 = life 26，前一圈未灭下一圈已生；stroke 2.5→3、基不透明度 0.6→0.7）：「膜不断被穿过」的动词动作，把 1502–1568 的段持续抬到 diff 0.5–0.7。
- **SC04 第三穿 1618–1648**：分镜写「来回穿 2 次」+ 尾部仅一颗点缓慢绕行；实测绕行/波纹/光呼吸对采样都 <0.35（最长静止 4.1s）。按 §7「加大幅度不加信息」增第三穿（同图元同语义「拦不住」，收尾 1648 → 稳定期 1648–1686 = 38f ≥30）。**这是对分镜的一处偏离，报主会话确认**；若坚持两穿，可把第二穿后移到 ~1530 并把绕行 lap 从 66 降到 48（实测仍不足 0.35，需再议）。
- **手掌图标（parts.tsx HandPart）**：四指胶囊 + 掌心 + 拇指 + 指甲；指甲宽及指缘（甲缘描边与指侧描边重合）→ stick_check 里整只手是一个连通分量，无新增误报。
- **frame_metrics hero 折算**：SC03 数字行（104px Orbitron 墨迹 ~75px）单行不达 170，靠单位行（y374，间距 ≤26px）压成一簇（w≈480 → min(w,4h)/2.5 折算 210px）当主体；手掌刻意压到 175×185 当配角且无光。
- **数字/术语均出自事实清单**：650 亿（个/秒/平方厘米，research §环境 2 ★ 二手）、「? eV」（质量未测得，§4）。「0」命中数为换算结论（一生命中 0），3→0 倒计数是视觉处理（12 帧）不是事实声明。
