## 关键参数 / 决策

- **SC07 相机方向**：CameraRig 起始相机 y=250（内容落屏 +110px，全部 y≤607 不触字幕带），3350–3370 移到 y=360（整组上移 110px 露出底部「~100」）。世界坐标 = 落位后坐标：顶标签 130 / 小卡排 178–224 / 漏斗 250–364 / 紫点簇 406–430 / 「~100」墨迹 482–552 / 单位字 569–593。
- **落卡防粘连（初版出图后实测修正）**：初版用「随机收敛目标 640±100」，vision 抽查 f_3356/3370 发现漏斗口卡片挤成一团（粘连）。改为 **4 条定宽流道**：slotX = 562/608/654/700（pitch 46、卡 34 宽、净空 12px ≥ 要求），11 列车道按 i%4 归流道，同流道卡片相隔 ≥12 帧（纵向也分离）；流道两端距漏斗底口边缘（530/750）≥15px，不贴漏斗壁。复测 f_3370 卡片「边界清晰、不合并」。
- **veto 半圆方向（初版出图后实测修正）**：初版 `A…0 0 1` 弧向上凸（vision 抽查 3304/3478 确认），改为 `0 0 0` 使地球截面在冰面之下（向下凸），符合「只收从地底钻上来的」语义；复测 3478 确认。
- **被拒卡「出画」改法**：分镜写「变灰加速下落出画」，因字幕带 y637 版式安全限制，改为「漏斗内吞噬 + 底口甩出后 45px 内快速淡出」（y≤415 前 opacity=0，相机压低相时屏幕 ≤580）。语义不变（筛掉背景），如需严格出画要重排纵向空间。
- **「~100」前挂 3428**：分镜停留栏「末块 S22 26 帧短：前挂到 3428」→ 计数 3350→3428 共 78 帧（ease 1.3 次幂）落定即脉冲 3432。
- **SC08 主角连通**：信封 240×180（h=180 >170 留余量）+ 年份 128px + Pill 以 ≤10px 间距连通成 334px 主体（单行大字只 ~127px，必须靠连通块达标）。信封↔年份净空 4px、年份↔Pill 10px、Pill↔能量标 23px、能量标↔轴 27px。
- **信 1 承接位移**：缩 0.6 + 左移 60，transformOrigin 锚在轴节点（280,540）（茎线随之缩向节点）；信 1 的 Pill 与能量标签随位移淡出（信 2 同款标签接棒），避免 13–18px 的缩小文字成为低可读碎屑。
- **时间线刻度为示意排布**：2013/2017/2022/2026 在 x 280/640/880/1080（非严格等比），为给两张 240 宽信卡 + ≥60px 组间净空让位；两信卡中心距 360（信 1 缩后净空 106px）。
