## 抽象出的规则（写进 skill lessons + memory）

1. Yunxi（以及同类神经 TTS）在**无标点长块**上会"节拍贪停"——块越长（节拍越多）碎得越厉害
2. 反教训：**不要用"密集加逗号"修断句**——实验证明停顿数量不降反升（S25 从 3 处变 4 处），且成片明显变长
3. 正解：写稿时**按自然朗读语感补标点**（主谓分界逗号、句末句号、问号保留），配合 RATE 微调控时长——压字间（+8%）保留标点停顿，可在不掉听感的前提下把时长压回档位
4. 用户听感的共性是**「停顿充分 / 整体可偏慢」**，而非"标点本身"——归因对照实验（v0_slow 纯慢版同样被接受）证明这一点
5. 工作法教训：人耳反馈优先于我自己的量化指标——三轮"停顿数量/时长"优化被指标带歪（自以为更差回退了 v1，其实用户要的就是它）；先拿用户判断、再归因、最后才是量化验证
6. 交付方法：逐段验收必须配**逐段时间戳表**，只给整片音频路径用户无法回报具体位置
